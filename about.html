About

Post-Bayesian methods are spread across statistics, machine learning, econometrics and learning theory, and the same idea often turns up under different names: Gibbs posteriors, generalised Bayes, loss-based updating, tempered posteriors, PAC-Bayes. This repository collects them in one searchable place under a common set of tags, so it is easier to see how the pieces connect and to find the paper you half-remember.

What counts as “post-Bayesian”?

We include work that still produces a distribution over parameters or predictions, but changes how that distribution is built. Usually this is because the standard Bayesian posterior is unreliable (the model or prior is misspecified), impractical (the likelihood or posterior is intractable), or aimed at the wrong target (prediction matters more than parameter recovery). Work that only computes the standard posterior more efficiently, such as faster MCMC, is out of scope.

How papers are tagged

Post-Bayesian class

A paper can belong to more than one class. Each class is explained on the Background page.

  • Generalised Bayes Gibbs (generalised) posteriors, which replace the likelihood with a loss function: robust losses, learning-rate choice and computation, plus closely related work such as power posteriors and generalised variational inference.
  • Predictively Oriented Posteriors Posteriors that score the posterior predictive itself, and their PAC-Bayesian precursors.
  • Martingale Posteriors Predictive resampling and other predictive approaches, including the Bayesian bootstrap.
  • PAC-Bayes Generalisation bounds and the frequentist theory used to analyse and design post-Bayesian methods.

Contribution style

  • Theory: consistency, concentration, asymptotics, generalisation bounds, axiomatic justification.
  • Method: a new posterior, loss, algorithm, or calibration procedure.
  • Application: uses post-Bayesian ideas to solve a substantive applied problem.
  • Review: surveys, tutorials and position papers.

Contributing

Contributions are very welcome. There are two ways to add a paper:

  1. Open an issue on GitHub with a link to the paper and the class and contribution style you would suggest.
  2. Open a pull request adding a row to data/papers.csv. The easiest way is to run python3 scripts/add_paper.py <arXiv ID or DOI> in a clone of the repository: it looks up the metadata, asks for the tags and adds the row for you. To edit the file by hand instead: use the published venue and year where they exist (otherwise arXiv preprint), put the author list in quotes, always give the arXiv link when there is one, add the published link (DOI or proceedings page) if the paper has appeared, and separate multiple classes or styles with a semicolon: 
    title,authors,year,venue,arxiv,published,class,contribution
Martingale posterior distributions,"Edwin Fong, Chris Holmes, Stephen G. Walker",2023,Journal of the Royal Statistical Society: Series B,https://arxiv.org/abs/2103.15671,https://doi.org/10.1093/jrsssb/qkad005,Martingale Posteriors,Theory; Method

Found a mistake in an entry, or think a paper is mis-tagged? Please open an issue as well.
