About

Post-Bayesian methods are spread across statistics, machine learning, econometrics and learning theory, and the same idea often turns up under different names: Gibbs posteriors, generalised Bayes, loss-based updating, tempered posteriors. This repository collects them in one searchable place under a common set of tags, so it is easier to see how the pieces connect and to find the paper you half-remember.

What Counts as “Post-Bayesian”?

We include work that still produces a distribution over parameters or predictions, but changes how that distribution is built. Usually this is because the standard Bayesian posterior is unreliable (the model or prior is misspecified), impractical (the likelihood or posterior is intractable), or aimed at the wrong target (prediction matters more than parameter recovery). Work that only computes the standard posterior more efficiently, such as faster MCMC, is out of scope.

Scope and Precedents

The table lists work from Bissiri, Holmes & Walker (2016) onwards, which framed general loss-based belief updating. Many of the ideas have a longer history, and the following earlier papers are important precedents:

  • Donald B. Rubin (1981). The Bayesian bootstrap. Annals of Statistics. [published]
  • Michael A. Newton, Adrian E. Raftery (1994). Approximate Bayesian inference with the weighted likelihood bootstrap. Journal of the Royal Statistical Society: Series B. [published]
  • David A. McAllester (1999). Some PAC-Bayesian theorems. Machine Learning. [published]
  • Olivier Catoni (2007). PAC-Bayesian supervised classification: the thermodynamics of statistical learning. IMS Lecture Notes Monograph Series. [arXiv · published]
  • Peter Grünwald (2012). The safe Bayesian: learning the learning rate via the mixability gap. Algorithmic Learning Theory (ALT). [published]
  • Stephen G. Walker (2013). Bayesian inference with misspecified models. Journal of Statistical Planning and Inference. [published]
  • Giles Hooker, Anand N. Vidyashankar (2014). Bayesian model robustness via disparities. TEST. [arXiv · published]

How Papers Are Tagged

Topic

A paper can have more than one topic. Each topic is explained on the Background page. The first three are post-Bayesian approaches; PAC-Bayes is included as a closely related theoretical framework.

  • Generalised Bayes Gibbs (generalised) posteriors, which replace the likelihood with a loss function: robust losses, learning-rate choice and computation, plus closely related work such as power posteriors and generalised variational inference.
  • Predictively Oriented Posteriors Posteriors that score the posterior predictive itself, and their PAC-Bayesian precursors.
  • Martingale Posteriors Predictive resampling and other predictive approaches, including the Bayesian bootstrap.
  • PAC-Bayes Not itself a post-Bayesian method, but a closely related theoretical framework: generalisation bounds for distributions over parameters, which are used to analyse and design post-Bayesian methods.

Contribution Style

  • Theory: consistency, concentration, asymptotics, generalisation bounds, axiomatic justification.
  • Method: a new posterior, loss, algorithm, or calibration procedure.
  • Application: uses post-Bayesian ideas to solve a substantive applied problem.
  • Review: surveys, tutorials and position papers.

Contributing

Contributions are very welcome. There are two ways to add a paper:

  1. Open an issue on GitHub with a link to the paper and the topic and contribution style you would suggest.
  2. Open a pull request adding a row to data/papers.csv. The easiest way is to run python3 scripts/add_paper.py <arXiv ID or DOI> in a clone of the repository: it looks up the metadata, asks for the tags and adds the row for you. To edit the file by hand instead: use the published venue and year where they exist (otherwise arXiv preprint), put the author list in quotes, always give the arXiv link when there is one, add the published link (DOI or proceedings page) if the paper has appeared, and separate multiple topics or styles with a semicolon: 
    title,authors,year,venue,arxiv,published,class,contribution
Martingale posterior distributions,"Edwin Fong, Chris Holmes, Stephen G. Walker",2023,Journal of the Royal Statistical Society: Series B,https://arxiv.org/abs/2103.15671,https://doi.org/10.1093/jrsssb/qkad005,Martingale Posteriors,Theory; Method

Found a mistake in an entry, or think a paper is mis-tagged? Please open an issue as well.
